# Password Generator 🔐
A simple Python offline password generator.

## Features
 - Choose password length
 - Generate multiple passwords
 - Uppercase and lowercase letters
 - Numbers
 - Special characters

## How to run
```bash
python password_generator.py
```

## What I learned
 - Python functions
 - Loops
 - Lists
 - Input validation
 - Error Handling
 - Using the `secrets` module
